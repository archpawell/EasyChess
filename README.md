# 2D Top-Down PvP Chess (Antigravity Ready Project)

## Quick Start in Antigravity
1. Extract this `.zip` archive or import it directly into your Antigravity workspace.
2. Open `index.html` in the preview or browser—no build step or external server required.
3. Refer to `ANTIGRAVITY_PROMPT.md` for the complete architectural prompt and feature specification if you want Antigravity AI to add new features (such as PGN export, chess clocks, sound effects, or WebRTC online multiplayer).

## Project Files
- `index.html` — Self-contained application containing the 2D Top-Down UI, complete Chess Engine, Tactical Overlays, Field & Figure Color Pickers, Handicap Mode, Unlimited Undo Timeline, and Skin Pack Manager.
- `ANTIGRAVITY_PROMPT.md` — Full text prompt and specification for Antigravity.
- `assets/guinea-pig-2/` — Pre-rendered standalone SVG figure assets for all 6 Guinea Pig2 chess pieces (White & Black variants).
